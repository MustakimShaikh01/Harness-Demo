# Testing

```bash
pytest -q
python banking_agent/evaluation/evaluation_runner.py
cargo test --locked --manifest-path rust/audit-verifier/Cargo.toml
cargo fmt --manifest-path rust/audit-verifier/Cargo.toml -- --check
```

The Python suite covers beneficiary management, policy boundaries, transfer and bill-payment integration, ADK sensitive-tool confirmation configuration, cross-customer authorization, approval modification/expiry/replay, malformed JSON, money validation, prepared-journal recovery and audit-chain generation/tamper detection. Tests use temporary directories and do not call Gemini. Rust unit tests cover valid chains, modified events, reordering and unhashed legacy events. CI also verifies an audit log generated by the Python logger with the Rust CLI.

The evaluation runner executes every pytest node ID linked in `banking_agent/evaluation/test_cases.json` and reports scenario-level outcomes. Prompt-safety checks validate instruction boundaries, not model resistance against every possible injection; this is not model-red-team certification. Live Gemini testing is separate and optional:

```bash
python scripts/smoke_agent.py
```

That script sends one short model request and can incur API usage.
